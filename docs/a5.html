A5: Transistors - Smart & Anti-theft Nightlight

For Assignment 5, I built a smart lighting system that controls a high-load 12V LED strip using an IRLZ44N N-MOSFET. It acts as an ambient nightlight using a PIR motion sensor and a photoresistor. Touching a capacitive foil sensor triggers a "anti-theft Music Mode" where buzzer play a melody while the 12V LED strip visualizes the music notes!

1. Schematic & Circuit (Calculations & Justifications)

Hardware Configurations & Critical Calculations:

  • The High-Load Output (12V LED Strip & MOSFET):
    I am using an external 12V DC power supply to power the LED strip. The positive wire of the LED strip goes directly to the 12V power supply. The negative wire connects to the Drain (Pin 2) of the IRLZ44N N-MOSFET. The Source (Pin 3) goes to the common Ground (connecting Arduino GND and 12V GND). The Gate (Pin 1) connects to Arduino PWM Pin 9 through a 330Ω resistor (to protect the Arduino from inrush current to the gate capacitor), with a 10kΩ pull-down resistor to GND to ensure the MOSFET stays OFF when the Arduino is booting.
    Current Justification: My 1-meter 12V LED strip draws approximately 1.2A of current. According to the IRLZ44N datasheet, it can handle an absolute maximum continuous drain current of 47A at room temperature. Because 1.2A is vastly below 47A, the transistor will run safely without needing a heatsink.

  • Photoresistor (LDR) Voltage Divider (Pin A0):
    I used a 10kΩ fixed resistor in series with the LDR.
    - In bright room light (LDR ≈ 2kΩ): Expected Voltage Vout = 5V × [ 10kΩ / (2kΩ + 10kΩ) ] = 4.17V.
    - In the dark (LDR ≈ 20kΩ): Expected Voltage Vout = 5V × [ 10kΩ / (20kΩ + 10kΩ) ] = 1.67V.
    This confirms my darkThreshold in the code (analog reading around 400-500) will accurately detect nighttime.

  • Input with Library (Capacitive Touch on Pins 4 & 2):
    To fulfill the library requirement, I used aluminum foil as a capacitive touch button. A 1MΩ resistor sits between the Send Pin (4) and Receive Pin (2). 1MΩ provides a fast and reliable touch detection range, preventing false triggers while reacting instantly to direct touch to start the music.

2. Circuit Operation

Caption: Daytime: The LED strip remains off regardless of motion.
Nighttime: When the PIR detects motion, the LED strip smoothly fades in via PWM. If motion stops, a 10-second timer counts down before fading out.
Anti-theft Mode: When the capacitive foil is touched, the system enters an interrupt sequence. Buzzer play a rapid-alternating melody, and the LED strip brightness scales dynamically using analogWrite() synced to the musical notes!

// Include the CapacitiveSensor library to use the foil touch sensor
#include 
// Include the standard pitches library for music notes
#include "pitches.h"

// Define the PWM pin that controls the N-MOSFET (LED Strip)
const int mosfetPin = 9;
// Define the analog pin for the LDR voltage divider
const int ldrPin = A0;
// Define the digital pin for the PIR motion sensor
const int pirPin = 7;
// Define the digital pin for the Melody Buzzer
const int buzzerPin = 10;

// Initialize the capacitive sensor with Send pin 4 and Receive pin 2
CapacitiveSensor capSensor = CapacitiveSensor(4, 2);

// Set the threshold for the LDR to distinguish day from night
const int darkThreshold = 500;
// Set the threshold for capacitive touch to trigger music
const long touchThreshold = 300;

// Track the current brightness of the LED strip for fading
int currentBrightness = 0;
// Store the timestamp of the last detected motion
unsigned long lastMotionTime = 0;
// Set the duration to keep lights on after motion stops (10 seconds)
const unsigned long lightDuration = 1000;
// Track whether the night light is currently active
bool isLightOn = false;

// The setup function runs once when the board is powered on
void setup() {
  // Initialize serial communication for debugging purposes
  Serial.begin(9600);

  // Set the MOSFET pin as OUTPUT. This configures the pin to a low-impedance state, currently driving 0V (LOW), keeping the transistor Gate discharged and the LED strip completely OFF.
  pinMode(mosfetPin, OUTPUT);
  
  // Set the PIR sensor pin as INPUT. This places the pin in a high-impedance state to passively listen for 0V or 5V signals from the motion module.
  pinMode(pirPin, INPUT);
  
  // Set the Buzzer pin as OUTPUT. It is in a low-impedance state outputting 0V, making no sound.
  pinMode(buzzerPin, OUTPUT);
  
  // Explicitly ensure the MOSFET is turned off at startup
  analogWrite(mosfetPin, 0);
}

// The main loop function runs continuously
void loop() {
  // Read the current light level from the LDR
  int lightLevel = analogRead(ldrPin);
  
  // Read the current motion state from the PIR sensor
  int motionDetected = digitalRead(pirPin);
  
  // Read the capacitive sensor value (taking 30 samples for stability)
  long touchValue = capSensor.capacitiveSensor(30);

  // Check if the capacitive foil is touched (Music Mode Trigger)
  if (touchValue > touchThreshold) {
    // Call the function to play music and flash lights
    playMusicShow();
    // After music finishes, reset the motion timer to avoid instant shutoff
    lastMotionTime = millis();
  }

  // Check if it is currently dark enough to need the night light
  if (lightLevel < darkThreshold) {
    
    // Check if the PIR sensor is currently detecting motion
    if (motionDetected == HIGH) {
      // Update the last motion timestamp to the current time
      lastMotionTime = millis();
      
      // Check if the light is currently off
      if (!isLightOn) {
        // Slowly fade the LED strip in
        fadeIn();
        // Update the state flag to indicate the light is on
        isLightOn = true;
      }
    }

    // Calculate how much time has passed since the last motion
    unsigned long timeSinceMotion = millis() - lastMotionTime;

    // Check if the light is on AND the 10-second timer has expired
    if (isLightOn && (timeSinceMotion > lightDuration)) {
      // Slowly fade the LED strip out
      fadeOut();
      // Update the state flag to indicate the light is off
      isLightOn = false;
    }
    
  } 
  // If it is daytime (bright), ensure the light turns off
  else {
    // Check if the light is currently on
    if (isLightOn) {
      // Slowly fade the LED strip out
      fadeOut();
      // Update the state flag to indicate the light is off
      isLightOn = false;
    }
  }
}

// Function to smoothly increase the MOSFET PWM duty cycle
void fadeIn() {
  // Loop from 0 to 255 to increase brightness
  for (int i = 0; i <= 255; i++) {
    // Write the current PWM value to the MOSFET Gate
    analogWrite(mosfetPin, i);
    // Wait for 5 milliseconds to create a smooth visual transition
    delay(5);
  }
  // Store the final maximum brightness state
  currentBrightness = 255;
}

// Function to smoothly decrease the MOSFET PWM duty cycle
void fadeOut() {
  // Loop from current brightness down to 0
  for (int i = currentBrightness; i >= 0; i--) {
    // Write the current PWM value to the MOSFET Gate
    analogWrite(mosfetPin, i);
    // Wait for 10 milliseconds to create a slow, sleepy fade out
    delay(10);
  }
  // Store the final zero brightness state
  currentBrightness = 0;
}

// Function to play single-tone music and visualize it on the LED strip
void playMusicShow() {
  // Define an array of frequencies for the Melody
  int melody[] = {NOTE_A5, NOTE_C6, NOTE_F5, NOTE_A5, 
                  NOTE_G5, NOTE_C6, NOTE_E5, NOTE_G5, 
                  NOTE_F5, NOTE_A5, NOTE_D5, NOTE_F5,
                  NOTE_E5, NOTE_A5, NOTE_C5, NOTE_E5,
                  NOTE_D5, NOTE_F5, NOTE_AS4, NOTE_D5,
                  NOTE_C5, NOTE_F5, NOTE_A4, NOTE_C5,
                  NOTE_AS4, NOTE_C5, NOTE_D5, NOTE_E5,
                  NOTE_F5, NOTE_G5, NOTE_A5};
  
  // Define an array for the duration of each note in milliseconds
  int noteDurations[] = {100, 100, 100, 100, 
                         100, 100, 100, 100,
                         100, 100, 100, 100, 
                         100, 100, 100, 100,
                         100, 100, 100, 100,
                         100, 100, 100, 100,
                         100, 100, 100, 100,
                         250, 250, 800};
  int numMelo = sizeof(noteDurations) / sizeof(noteDurations[0]); 
  // Loop through all 7 notes in the arrays
  for (int thisNote = 0; thisNote < numMelo; thisNote++) {
    // Map the pitch of the melody note to a PWM brightness value (0-255)
    // NOTE_C6 is approx 1047Hz, scaling down for standard notes
    int ledBrightness = map(melody[thisNote], 0, 1100, 0, 255);
    
    // Write the mapped brightness to the 12V LED Strip via MOSFET
    analogWrite(mosfetPin, constrain(ledBrightness, 0, 255));

    // Get the duration for the current note
    int duration = noteDurations[thisNote];
    
    // Play the melody note for the specified duration
    tone(buzzerPin, melody[thisNote], duration);
    
    // Wait for the note to finish playing
    delay(duration);
    
    // Stop any remaining sound from the buzzer
    noTone(buzzerPin);
    
    // Turn off the LED strip momentarily to visually separate the notes
    analogWrite(mosfetPin, 0);
    
    // Add a short 50-millisecond pause between musical notes for articulation
    delay(20);
  }
}

Question 3: L293D Dual Motor Control

Here is the datasheet for the L293D chip. Draw a schematic using at least your arduino, this chip, and two motors. Write (pseudo) code that shows how you would move the motors both forward, both back, then one forward one back, and one back then forward.

Answer & Pseudocode:
The L293D is a an H-Bridge. Motor 1 connects to output pins 1Y (Pin 3) and 2Y (Pin 6). Motor 2 connects to output pins 3Y (Pin 11) and 4Y (Pin 14). The Arduino controls them via the input pins (1A, 2A for Motor 1; 3A, 4A for Motor 2). By reversing the HIGH/LOW logic on the inputs, the motors reverse direction. 


// Define Arduino pins connected to L293D Inputs
int motor1_A = 2; // L293D Pin 1A
int motor1_B = 3; // L293D Pin 2A
int motor2_A = 4; // L293D Pin 3A
int motor2_B = 5; // L293D Pin 4A

void setup() {
  pinMode(motor1_A, OUTPUT); pinMode(motor1_B, OUTPUT);
  pinMode(motor2_A, OUTPUT); pinMode(motor2_B, OUTPUT);
}

void loop() {
  // 1. BOTH MOTORS FORWARD
  digitalWrite(motor1_A, HIGH); digitalWrite(motor1_B, LOW);
  digitalWrite(motor2_A, HIGH); digitalWrite(motor2_B, LOW);
  delay(2000);

  // 2. BOTH MOTORS BACKWARD
  digitalWrite(motor1_A, LOW); digitalWrite(motor1_B, HIGH);
  digitalWrite(motor2_A, LOW); digitalWrite(motor2_B, HIGH);
  delay(2000);

  // 3. ONE FORWARD, ONE BACKWARD (e.g., Robot turning right)
  digitalWrite(motor1_A, HIGH); digitalWrite(motor1_B, LOW);
  digitalWrite(motor2_A, LOW);  digitalWrite(motor2_B, HIGH);
  delay(2000);

  // 4. ONE BACKWARD, ONE FORWARD (e.g., Robot turning left)
  digitalWrite(motor1_A, LOW);  digitalWrite(motor1_B, HIGH);
  digitalWrite(motor2_A, HIGH); digitalWrite(motor2_B, LOW);
  delay(2000);
}
