A3: InputOutput - Smart Home Ambient Light

Welcome to “Smart Ambient Lighting”! This system uses photoresistors, thermistors, and ultrasonic sensors to detect ambient light, room temperature, and human presence. It uses these sensors to assess the environment and dynamically adjust the dual RGB LED lights to create different atmospheres in your home. At night, it automatically switches to night light mode, and it turns off automatically when no one is home to conserve energy.

1. Schematic & Circuit

Caption: The schematic above shows the complete wiring for the dual RGB LEDs, the button with an internal pull-up resistor, the buzzer, the ultrasonic sensor, and the two voltage dividers for the photoresistor and thermistor.

Resistor & Voltage Divider Calculations:

  • Photoresistor (LDR) Voltage Divider (Pin A0):
    I connected the photoresistor as R1 (connected to 5V) and a fixed resistor R2 = 10kΩ (connected to GND). Under bright indoor/sunny light, the LDR resistance drops to roughly 1kΩ to 2kΩ; in darkness, it rises to over 50kΩ.
    Using the voltage divider formula: Vout = Vin × [ R2 / (R1 + R2) ]:
    - In bright light (assume R1 = 1.5kΩ): Vout = 5V × [ 10kΩ / (1.5kΩ + 10kΩ) ] = 4.35V. The 10-bit analogRead() value will be roughly: (4.35V / 5V) × 1023 ≈ 890.
    - In darkness (assume R1 = 20kΩ): Vout = 5V × [ 10kΩ / (20kΩ + 10kΩ) ] = 1.67V. The analogRead() value will be roughly: (1.67V / 5V) × 1023 ≈ 341.
    Choosing a 10kΩ fixed resistor maximizes the voltage swing across my target lighting conditions, giving me clear thresholds in my code (darkThresh = 750 and sunnyThresh = 900).

  • Thermistor (NTC) Voltage Divider (Pin A1):
    I used a standard 10kΩ NTC thermistor at room temperature (25°C). To get the best sensitivity around room temperature, the fixed resistor R2 should match the thermistor's nominal resistance. Therefore, I chose a 10kΩ resistor.
    At 25°C (R1 = 10kΩ), Vout = 5V × [ 10kΩ / (10kΩ + 10kΩ) ] = 2.50V, which corresponds to an analogRead() value of around 512. When warmed up by hand or warm air, its resistance drops to ~8kΩ, raising Vout to 5V × (10 / 18) = 2.78V (an analogRead() value of ~569, which crosses my tempThresh = 565).

  • Dual RGB LED Current-Limiting Resistors (Pins 5, 9, 10):
    Because I wired two RGB LEDs in parallel to the same three PWM pins (Pins 5, 9, and 10), each Arduino pin supplies current to two LED channels simultaneously. The maximum safe current per Arduino I/O pin is 20mA to 40mA. Assuming a 2.0V forward voltage (Vf) for the Red channel and using a 330Ω resistor for each individual LED leg:
    I = (Vcc - Vf) / R = (5V - 2.0V) / 330Ω = 9.1mA per LED.
    With two LEDs in parallel, the total current drawn from a single Arduino pin is 9.1mA × 2 = 18.2mA (and even less for Green and Blue, which have a ~3.2V forward voltage, drawing ~5.5mA × 2 = 11mA). This keeps every pin safely below the 20mA continuous current limit!

void setup() {
  // Start the serial communication at 9600 baud rate

  // Configure the ultrasonic trig pin as output

  // Configure the ultrasonic echo pin as input
  pinMode(echoPin, INPUT);
  // Configure the buzzer pin as output
  pinMode(buzzerPin, OUTPUT);
  
  // Configure the Red LED pin as output

  // Configure the Green LED pin as output

  // Configure the Blue LED pin as output

// Declare the main loop function that runs repeatedly
void loop() {
  // Store the current time in milliseconds to avoid multiple calls
  unsigned long currentMillis = millis();

  // Read the current physical state of the button pin
  int reading = digitalRead(buttonPin);
  
  // Check if the button reading changed from the last loop
  if (reading != lastButtonState) {
    // Reset the debouncing timer
    lastDebounceTime = currentMillis;
  }
  
  // Check if the state has been stable longer than the debounce delay
  if ((currentMillis - lastDebounceTime) > debounceDelay) {
    // Check if the stable reading is different from the recorded logical state
    if (reading != buttonState) {
      // Update the logical button state to match the stable reading
      buttonState = reading;
      
      // Trigger action only when the button is released (goes HIGH)
      if (buttonState == HIGH) {
        // Toggle the system power state
        systemOn = !systemOn; 
        
        // Check if the system was just turned ON
        if (systemOn) {
          // Play the ascending boot sound
          playBootSound();
          // Reset the movement timer so lights turn on immediately
          lastMoveTime = currentMillis; 
        } 
        // Execute if the system was just turned OFF
        else {
          // Play the descending shutdown sound
          playShutdownSound();
          // Set the target Red LED brightness to zero
          targetR = 0;
          // Set the target Green LED brightness to zero
          targetG = 0;
          // Set the target Blue LED brightness to zero
          targetB = 0;
        }
      }
    }
  }
  // Save the reading for the next loop comparison
  lastButtonState = reading;

  // Execute sensor readings ONLY if the main system is ON
  if (systemOn) {
    // Check if 100ms have passed since the last ultrasonic ping
    if (currentMillis - lastPingTime > 100) {
      // Update the last ping time
      lastPingTime = currentMillis;
      
      // Call the function to get distance in centimeters
      long distance = getDistance();
      // Read the light level from the photoresistor
      int lightLevel = analogRead(ldrPin);
      // Read the temperature level from the thermistor
      int tempLevel = analogRead(ntcPin);

      // Check if it is time to print data to the serial monitor (every 500ms)
      if (currentMillis - lastPrintTime > 500) {
        // Update the last print time
        lastPrintTime = currentMillis;
        // Print the label for the light reading
        Serial.print("Light: ");
        // Print the actual light sensor value
        Serial.print(lightLevel);
        // Print the label for the temperature reading
        Serial.print(" | Temp: ");
        // Print the actual temperature sensor value
        Serial.print(tempLevel);
        // Print the label for the distance reading
        Serial.print(" | Dist: ");
        // Print the actual ultrasonic distance value
        Serial.print(distance);
        // Print the unit and move to a new line
        Serial.println(" cm");
      }

      // Check if the environment is considered Dark (Night Mode)
      if (lightLevel < darkThresh) {
        // Check if a person is detected within the night distance threshold
        if (distance > 0 && distance < nightDistThresh) {
          // Update the last move time for night mode
          lastMoveTime = currentMillis;
        }
        
        // Check if the time since last movement is within the night timeout
        if (currentMillis - lastMoveTime < nightTimeout) {
          // Set target Red channel to night light value
          targetR = nightR;
          // Set target Green channel to night light value
          targetG = nightG;
          // Set target Blue channel to night light value
          targetB = nightB;
        } 
        // Execute if no movement was detected within the timeout
        else {
          // Turn off the Red LED channel to save power
          targetR = 0;
          // Turn off the Green LED channel to save power
          targetG = 0;
          // Turn off the Blue LED channel to save power
          targetB = 0;
        }
      } 
      // Execute if the environment is considered Bright (Day Mode)
      else {
        // Check if a person is detected within the high-sensitivity day threshold
        if (distance > 0 && distance < dayDistThresh) {
          // Update the last move time for day mode
          lastMoveTime = currentMillis;
        }
        
        // Check if the time since last movement is within the day timeout
        if (currentMillis - lastMoveTime < dayTimeout) {
          // Constrain the light reading between darkThresh and 1023 for safe mapping
          int constrainedLight = constrain(lightLevel, darkThresh, 1023);
          // Use map() to dynamically scale brightness factor from 60% to 100% based on daylight intensity
          int brightnessScale = map(constrainedLight, darkThresh, 1023, 150, 255);
          
          // Check Condition 1: High Brightness (Sunny weather)
          if (lightLevel >= sunnyThresh) {
            // Check if the temperature is Hot
            if (tempLevel >= tempThresh) {
              // Scale and set Red channel for Hot + Sunny (Pure Blue)
              targetR = (hotBrightR * brightnessScale) / 255;
              // Scale and set Green channel for Hot + Sunny (Pure Blue)
              targetG = (hotBrightG * brightnessScale) / 255;
              // Scale and set Blue channel for Hot + Sunny (Pure Blue)
              targetB = (hotBrightB * brightnessScale) / 255;
            } 
            // Execute if the temperature is Cold
            else {
              // Scale and set Red channel for Cold + Sunny (Pure Red)
              targetR = (coldBrightR * brightnessScale) / 255;
              // Scale and set Green channel for Cold + Sunny (Pure Red)
              targetG = (coldBrightG * brightnessScale) / 255;
              // Scale and set Blue channel for Cold + Sunny (Pure Red)
              targetB = (coldBrightB * brightnessScale) / 255;
            }
          } 
          // Check Condition 2: Low Brightness (Cloudy weather)
          else {
            // Check if the temperature is Hot
            if (tempLevel >= tempThresh) {
              // Scale and set Red channel for Hot + Cloudy (Pink)
              targetR = (hotDimR * brightnessScale) / 255;
              // Scale and set Green channel for Hot + Cloudy (Pink)
              targetG = (hotDimG * brightnessScale) / 255;
              // Scale and set Blue channel for Hot + Cloudy (Pink)
              targetB = (hotDimB * brightnessScale) / 255;
            } 
            // Execute if the temperature is Cold
            else {
              // Scale and set Red channel for Cold + Cloudy (Orange/Yellow)
              targetR = (coldDimR * brightnessScale) / 255;
              // Scale and set Green channel for Cold + Cloudy (Orange/Yellow)
              targetG = (coldDimG * brightnessScale) / 255;
              // Scale and set Blue channel for Cold + Cloudy (Orange/Yellow)
              targetB = (coldDimB * brightnessScale) / 255;
            }
          }
        } 
        // Execute if nobody is detected for the timeout period in day mode
        else {
          // Fade out Red channel to standby mode
          targetR = 0;
          // Fade out Green channel to standby mode
          targetG = 0;
          // Fade out Blue channel to standby mode
          targetB = 0;
        }
      }
    }
  }

  // Run the smooth LED fading engine every 10 milliseconds
  if (currentMillis - lastFadeTime > 10) {
    // Update the last fade time
    lastFadeTime = currentMillis;
    
    // Increment Red brightness if below target
    if (currentR < targetR) currentR += 1.0;
    // Decrement Red brightness if above target
    else if (currentR > targetR) currentR -= 1.0;
    
    // Increment Green brightness if below target
    if (currentG < targetG) currentG += 1.0;
    // Decrement Green brightness if above target
    else if (currentG > targetG) currentG -= 1.0;
    
    // Increment Blue brightness if below target
    if (currentB < targetB) currentB += 1.0;
    // Decrement Blue brightness if above target
    else if (currentB > targetB) currentB -= 1.0;
    
    // Apply the calculated PWM value to the Red LED pin
    analogWrite(ledR, (int)currentR);
    // Apply the calculated PWM value to the Green LED pin
    analogWrite(ledG, (int)currentG);
    // Apply the calculated PWM value to the Blue LED pin
    analogWrite(ledB, (int)currentB);
  }
}

// Define function to play an ascending boot sound
void playBootSound() {
  // Play a 1046Hz tone for 100ms
  tone(buzzerPin, 1046, 100);
  // Wait for the tone to finish
  delay(100);
  // Play a 1318Hz tone for 100ms
  tone(buzzerPin, 1318, 100);
  // Wait for the tone to finish
  delay(100);
  // Play a 1568Hz tone for 150ms
  tone(buzzerPin, 1568, 150);
  // Wait for the tone to finish
  delay(150);
}

// Define function to play a descending shutdown sound
void playShutdownSound() {
  // Play an 884Hz tone for 100ms
  tone(buzzerPin, 884, 100);
  // Wait for the tone to finish
  delay(100);
  // Play a 351Hz tone for 200ms
  tone(buzzerPin, 351, 200);
  // Wait for the tone to finish
  delay(150);
}

// Define function to measure distance using the ultrasonic sensor without blocking
long getDistance() {
  // Clear the trig pin to LOW
  digitalWrite(trigPin, LOW);
  // Wait 2 microseconds
  delayMicroseconds(2);
  // Set the trig pin HIGH to send a sound wave
  digitalWrite(trigPin, HIGH);
  // Keep it HIGH for 10 microseconds
  delayMicroseconds(10);
  // Set the trig pin back to LOW
  digitalWrite(trigPin, LOW);
  
  // Wait up to 20000us for the echo pulse to return
  long duration = pulseIn(echoPin, HIGH, 20000); 
  
  // Check if pulseIn timed out (no object detected)
  if (duration == 0) return 999; 
  
  // Calculate and return distance in centimeters
  return duration * 0.034 / 2;
}

4. Additional Questions

Question 1: In your voltage divider, can the variable resistor be either R1 or R2 or does it need to be one or the other? Justify your answer with example calculations.

The variable resistor can be placed as either R1 (connected to Vin = 5V) or R2 (connected to GND); neither is strictly required by hardware, and both will form a working voltage divider. However, switching its position inverts the relationship between the physical change and the measured output voltage (Vout).

Using the voltage divider equation Vout = 5V × [ R2 / (R1 + R2) ], let's use a 10kΩ fixed resistor and a photoresistor whose resistance is 2kΩ in bright light and 20kΩ in the dark:

  • Case A: Variable Resistor as R1 (top) and 10kΩ Fixed Resistor as R2 (bottom, as wired in my circuit):
    - Bright light (R1 = 2kΩ): Vout = 5V × [ 10kΩ / (2kΩ + 10kΩ) ] = 4.17V (analogRead ≈ 853).
    - Darkness (R1 = 20kΩ): Vout = 5V × [ 10kΩ / (20kΩ + 10kΩ) ] = 1.67V (analogRead ≈ 341).
    Result: As brightness increases, Vout increases (intuitive positive correlation with light).

  • Case B: 10kΩ Fixed Resistor as R1 (top) and Variable Resistor as R2 (bottom):
    - Bright light (R2 = 2kΩ): Vout = 5V × [ 2kΩ / (10kΩ + 2kΩ) ] = 0.83V (analogRead ≈ 170).
    - Darkness (R2 = 20kΩ): Vout = 5V × [ 20kΩ / (10kΩ + 20kΩ) ] = 3.33V (analogRead ≈ 682).
    Result: As brightness increases, Vout decreases. Both configurations work equally well as long as you adjust your if-statement thresholds and map() direction in the code to match!

Question 3: AnalogWrite and analogRead are respectively 8-bit and 10-bit values. Imagine you had 10-bit PWM and a 16-bit analog-to-digital converter instead. How would this change your map() code? Explain your answer.

Standard Arduino uses a 10-bit ADC for analogRead(), which provides 210 = 1,024 discrete levels (ranging from 0 to 1023), and 8-bit PWM for analogWrite(), which provides 28 = 256 discrete levels (ranging from 0 to 255). A standard full-range mapping looks like:
map(val, 0, 1023, 0, 255);

If we instead had a 16-bit ADC and 10-bit PWM:

  • A 16-bit ADC provides 216 = 65,536 discrete levels, meaning analogRead() would return values ranging from 0 to 65535.
  • A 10-bit PWM provides 210 = 1,024 discrete levels, meaning analogWrite() would accept values ranging from 0 to 1023.

Therefore, a full-range map() function would change to:
map(val, 0, 65535, 0, 1023);

Specifically, in my smart home code where I map the daytime light sensor range (from darkThresh to the maximum ADC value) to a brightness factor between ~60% and 100% of maximum PWM:
- My current code (10-bit ADC to 8-bit PWM): map(constrainedLight, 750, 1023, 150, 255);
- With a 16-bit ADC and 10-bit PWM (scaling the thresholds proportionally: 750 / 1023 × 65535 ≈ 48046, and 150 / 255 × 1023 ≈ 602):
map(constrainedLight, 48046, 65535, 602, 1023);
